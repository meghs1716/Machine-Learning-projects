# Classification task of predicting obesity level

This project builds a machine learning system to predict obesity risk levels using lifestyle and  eating habits. 
It moves past basic modeling to focus on feature scaling,model interpretability and ensuring the model is  well generalized



# tech stack

languages & core: python, pandas,seabron,matplotlib

modelling: SVM, Decision Tree, Logistic Regression
